# ModeraX
AI-powered semantic retrieval system that preprocesses hate speech data, generates embeddings, and retrieves relevant context using Retrieval-Augmented Generation (RAG).

Tech Stack

Python
Pandas
NLTK
Sentence Transformers
FAISS
MongoDB
NumPy

Features

Dataset preprocessing and cleaning
Semantic embedding generation
Vector indexing with FAISS
Document storage in MongoDB
Fast similarity search
Top-5 contextual retrieval
LLM-ready context generation

Outputs

Cleaned dataset
Embedding vectors
FAISS vector database
Retrieved similar tweets
Context for AI-generated explanations
